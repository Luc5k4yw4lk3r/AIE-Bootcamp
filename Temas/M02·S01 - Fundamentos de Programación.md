### Qué hay que saber de Python, como mínimo

Con dedicación, entre 2 y 3 semanas:

- Variables
- Loops o iteraciones
- Condicionales
- Funciones
- Estructuras de datos: listas, diccionarios y sets
- Programación orientada a objetos
- Leer y escribir un archivo

### Técnicas de debug

- `print()` en los puntos clave para ver qué está pasando.
- El debugger de VS Code, para ir paso a paso.

### Cómo atacar un algoritmo

- Usar `print` para entender qué está haciendo el código en cada vuelta.
- Dibujar los intervalos de los `if`.
- Armar tablas de verdad.

### Pasos para iniciar un proyecto nuevo

Pedirle a Claude Code que:

- Cree un **entorno virtual**, para instalar la versión de Python y las librerías que necesita ese proyecto sin ensuciar el sistema.
- Deje configurada una forma de **depurar** el proyecto.

## Virtualización

Tres niveles de aislamiento, de menos a más:

- Entorno virtual (aísla las librerías de Python)
- Virtualización (aísla un sistema operativo entero)
- Docker (aísla la aplicación y sus dependencias en contenedores)
