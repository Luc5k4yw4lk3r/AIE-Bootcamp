## Mar
### Spotify Migrator — Mar

**Objetivo (*Goal*)** — poder migrar la información de Spotify a otras plataformas.

**Entradas (*Inputs*)**
- Archivo JSON con las playlists y canciones del usuario que quiere cambiar de plataforma.
- El JSON lo tiene que solicitar el propio usuario desde su perfil de Spotify.

**Salidas (*Outputs*)**
- La información del JSON se ingesta en una plataforma nueva de música, por ejemplo Tidal → [API de Tidal para desarrolladores](https://developer.tidal.com/).

**Diseño (*Layout*)**
- Interfaz minimalista.
- Experiencia de usuario simple.

**Características especiales (*Special features*)** — a definir.

**Entradas (*Inputs*)**
