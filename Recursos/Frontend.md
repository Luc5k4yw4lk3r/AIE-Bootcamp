# Claude Design
Como usar Claude Design
## Sincronizar
Desde nuestro proyecto en Vs Code activar Claude Code
- Lo primero es loguearse con el comando /design-login
- Sincronizar con el comando /design-sync
## Trabajar el proyecto
El proyecto se trabaja en modo iterativo desde Claude Design. La idea es ir haciendo comentarios sobre las distintas propuestas de diseño que nos va haciendo Claude.
## Llevar de Claude Design a Claude Code
Una vez seleccionada una maqueta que nos gusto. La tenemos que implementar en el código.
- **Descargar los cambios**: Desde el botón Share nos copiamos el prompt para descargar los cambios en el design system
- **Implementar los cambios**: Pedirle a Claude Design para implementar  un prompt. 
- **Imagenes**: Para los logos e imágenes pedirle a Claude Design que luego usaremos con Gemini Nano Banana
