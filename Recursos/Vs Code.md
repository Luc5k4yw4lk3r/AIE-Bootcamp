
# Init
1- Crear entorno virtual  
2- Activar entorno virtual  

```
python -m venv .venv 
source .venv/bin/activate # macOS / Linux 
.venv\Scripts\activate # Windows (PowerShell o cmd)
```
3- Instalar dependencias  
```
pip install fastapi 
pip install uvicorn

```
4- Sincronizar vscode con el interprete de python del venv  
5- Ejecutar python o el server en este caso
